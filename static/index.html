🌐网络
仅用于 GitHub 爬取（仓库扫描 / 脚本下载），不影响播放与灌入
镜像会真实拉取 GitHub 文件验证（识别假 200），并在 路径式/前缀式 两种拼接间自动回退；不使用镜像时走 jsDelivr → 直连 → 代理
勾选：代理 → 镜像 → 直连；不勾选（默认）：镜像 → 直连 → 代理。与镜像不互斥，仅调整优先级
GitHub API 未认证限额仅 60 次/小时，配额耗尽会爬取全部失败。点此直达 GitHub Token 创建页 ↗（登录 GitHub 即可，名称随意、有效期选长一点、权限一项都不用勾，点 Generate token 后复制生成的 token 粘贴到上面），限额提升到 5000 次/小时；留空则保持不变
